# FaceMix

[Open FaceMix](https://is0rynnx.github.io/facemix/)

Create face morphs and averages in your browser. Image processing runs on your device. The app does not upload your photos.

The library contains 492 images from [HumanPhenotypes.net](http://humanphenotypes.net/).

## Run locally

Use Node.js 22 or later.

```sh
npm ci
npm run build
npm start
```

Open `http://127.0.0.1:8768/`.
